Introducción

Android Studio permite construir la interfaz de una aplicación arrastrando componentes de la paleta (botones, listas desplegables, etiquetas y contenedores) sin escribir código, y genera el archivo XML de diseño. Los componentes se acomodan con restricciones (constraints) dentro de un ConstraintLayout.

Objetivos:

  • Diseñar una interfaz con el editor gráfico: botones, Spinner, TextView y LinearLayout vertical y horizontal.
  • Asignar texto e identificadores a cada componente.
  • Programar los escuchas de los botones en MainActivity.java.

Desarrollo

Parte I. Diseño de la interfaz

Se creó el proyecto ProgramacionGrafica con la plantilla Empty Views Activity, lenguaje Java y Minimum SDK API 31. En activity_main.xml (pestaña Design) se borró el TextView de la plantilla y se agregaron:

  • Un botón Desconectar anclado a la parte inferior, con ancho 0dp (match constraint).
  • Un LinearLayout vertical que ocupa el resto de la pantalla (0dp de ancho y alto, con sus cuatro lados restringidos).
  • Dentro, de arriba abajo: el botón Buscar, el Spinner de dispositivos, el botón Conectar, la etiqueta CONTROL LEDS (16sp, negrita) y dos LinearLayout horizontales con dos botones cada uno (Led1 ON y Led2 ON; Led1 OFF y Led2 OFF), con layout_weight="1" para repartir el ancho.

MainActivity.java. Cada botón tiene un OnClickListener que muestra un Toast; el botón Buscar además llena el Spinner con tres dispositivos de ejemplo (HC-05, HC-06 y ESP32-LEDS). La conexión Bluetooth real queda para la unidad de servicios y comunicaciones.

package com.example.programaciongrafica;

import android.os.Bundle;
import android.view.View;
import android.widget.ArrayAdapter;
import android.widget.Button;
import android.widget.Spinner;
import android.widget.Toast;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {
    Button IdBtnBuscar, IdBtnConectar, IdBtnLed1on, IdBtnLed1off, IdBtnLed2on,
            IdBtnLed2off, IdBtnDesconectar;
    Spinner IdDisEncontrados;

    @Override
    protected void onCreate(Bundle b) {
        super.onCreate(b);
        setContentView(R.layout.activity_main);
        IdBtnBuscar = findViewById(R.id.IdBtnBuscar);
        IdBtnConectar = findViewById(R.id.IdBtnConectar);
        IdBtnLed1on = findViewById(R.id.IdBtnLed1on);
        IdBtnLed1off = findViewById(R.id.IdBtnLed1off);
        IdBtnLed2on = findViewById(R.id.IdBtnLed2on);
        IdBtnLed2off = findViewById(R.id.IdBtnLed2off);
        IdBtnDesconectar = findViewById(R.id.IdBtnDesconectar);
        IdDisEncontrados = findViewById(R.id.IdDisEncontrados);

        IdBtnBuscar.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                // Dispositivos de ejemplo: la búsqueda Bluetooth real queda para la Unidad IV.
                String[] dispositivos = {"HC-05", "HC-06", "ESP32-LEDS"};
                IdDisEncontrados.setAdapter(new ArrayAdapter<>(MainActivity.this,
                        android.R.layout.simple_spinner_dropdown_item, dispositivos));
                aviso("Se digitó el botón Buscar");
            }
        });
        IdBtnConectar.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                Object elegido = IdDisEncontrados.getSelectedItem();
                aviso("Se digitó el botón Conectar" + (elegido != null ? ": " + elegido : ""));
            }
        });
        IdBtnLed1on.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                aviso("Se digitó el botón Led1 ON");
            }
        });
        IdBtnLed1off.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                aviso("Se digitó el botón Led1 OFF");
            }
        });
        IdBtnLed2on.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                aviso("Se digitó el botón Led2 ON");
            }
        });
        IdBtnLed2off.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                aviso("Se digitó el botón Led2 OFF");
            }
        });
        IdBtnDesconectar.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                aviso("Se digitó el botón Desconectar");
            }
        });
    }

    private void aviso(String texto) {
        Toast.makeText(getBaseContext(), texto, Toast.LENGTH_SHORT).show();
    }
}

Ejecución

Conclusiones

El editor gráfico permite armar la interfaz con rapidez, pero lo importante es entender el XML que genera: las restricciones del ConstraintLayout fijan la posición de cada componente y 0dp hace que ocupe el espacio disponible. Los identificadores deben ser únicos para poder enlazar cada botón con su escucha en Java. Esta pantalla queda lista para conectar los botones con un módulo Bluetooth cuando se vean los sensores y las comunicaciones del dispositivo.
